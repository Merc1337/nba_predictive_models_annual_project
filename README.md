# 🏀 NBA Player CPM Prediction Service

Разработка ML-сервиса для прогнозирования продвинутой метрики эффективности баскетболистов **CPM (Crafted Plus-Minus)** на основе статистических показателей предыдущих сезонов и внутрисезонной динамики.

---

## 📌 Цели проекта

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>📅 I семестр</h3>
      <p>Разработать ML-сервис, прогнозирующий <b>CPM игрока NBA на следующий сезон</b> по историческим данным прошлых сезонов.</p>
    </td>
    <td width="50%" valign="top">
      <h3>📅 II семестр</h3>
      <p>Расширить решение до прогноза <b>итогового CPM текущего сезона</b> по результатам первых $N$ сыгранных матчей.</p>
    </td>
  </tr>
</table>
